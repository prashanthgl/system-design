# Cheat Sheets

**Dense reference pages for the day before your interview — numbers, frameworks, decision trees, and checklists, without the narrative.**

| Cheat sheet | Use it for |
|---|---|
| [Numbers & Estimation](numbers.md) | Latency tables, QPS/storage/bandwidth conversions, availability math, queueing theory, a fully worked capacity example |
| [Interview Framework](interview-framework.md) | The 45-minute phase breakdown, clarifying-question checklists, Staff/Lead vs mid-level signals |
| [Decision Trees](decision-trees.md) | Database choice, partitioning strategy, consistency model, sync/async replication, queue-or-not, cache strategy, saga-or-not — as flowcharts |
| [Review Checklists](checklists.md) | Pre-design, API, data model, failure mode, SRE/operability, security, and cost checklists — as checkable statements, not vague reminders |
| [Papers & Further Reading](papers.md) | The primary sources behind the patterns, organized by category, linked back to the relevant pages on this site |

!!! tip "How to use these in the last 48 hours"
    Don't re-read case studies. Read the [Numbers cheat sheet](numbers.md) until the latency
    table and availability math are automatic, run through the [Interview Framework](interview-framework.md)
    checklist once out loud, and skim the [Decision Trees](decision-trees.md) to make sure you can
    redraw each one from memory. Save the [Review Checklists](checklists.md) for the last five
    minutes of your own mock interviews, not for passive reading.
